# The Rettington Gardener

This project is a custom Discord bot originally built for personal use but also shared with the community. At its core is
**Kohlrabi** – a small, watchful helper who tends to the server the way a gardener tends to a plot: quietly, consistently,
and with an eye for detail.

Kohlrabi handles the practical side of running a server:

- **Ticket System** – opens and manages support tickets, so questions and requests never get lost in the noise.

- **Role Management** – assigns and removes roles on request, keeping access and permissions tidy without manual effort.

- **Moderation** – automatically removes unwanted Discord invite links and helps keep the server clean and on-topic.

- **A Bit of Fun** – sprinkles in a few lighthearted commands here and there, because even a well-tended garden needs some color.

The goal is to combine reliable, low-maintenance server management with a bit of personality – something that quietly does its
job in the background, but still feels like part of the community rather than just a utility.

The bot is regularly updated to match personal preferences and the evolving needs of the server it grows in. While built
primarily for private use, its source is open for anyone curious to see how it works.
